密钥管理

使用 CC Switch 管理密钥

CC Switch 是开源的 AI 编程工具配置切换器，可统一管理 Claude Code、Codex、Open Claw 等工具的 API、模型和 MCP 配置。

  • 下载地址：https://ccswitch.io
  • 安装完成后，进入 LUTPOT 的 API 密钥界面，点击 导入到 CCS。
  • 平台的 codex 分组对应 CC Switch 的 codex 分组；平台的 claude 分组对应 CC Switch 的 claude code 分组。

小龙虾配置

OpenClaw / Harmes 手动配置

OpenClaw 可通过模型供应商配置接入自定义接口，Harmes 没有自动导入入口时，也按 OpenAI Compatible / Custom Provider 的方式填写平台接口信息。

先回到密钥管理页面复制三项信息

点击 使用密钥，复制页面提供的 Base URL、API Key 和模型名称。GPT / Codex / OpenAI 兼容工具优先使用 codex 分组；Claude 兼容工具使用 claude 分组。

Base URL API Key Model

OpenClaw 手动配置

适合需要直接配置模型供应商、默认模型和 Gateway 的用户。

  1. 01

    进入配置执行 openclaw onboard --install-daemon，或打开 openclaw dashboard 进入模型供应商配置。

  2. 02

    新增供应商选择 Custom Provider、OpenAI Compatible 或同类入口，供应商名称可以写 LUTPOT。

  3. 03

    填写模型Base URL 填 baseUrl，API Key 填 apiKey；默认模型按 provider/model 选择，例如 gpt-5.5。

  4. 04

    保存验证执行 openclaw models list 检查模型，再发一条短消息测试；不生效时重启 OpenClaw Gateway。

官方参考：Getting started、Provider directory、Model providers。

Harmes 手动配置

适合客户端没有自动导入入口，需要手动填写接口信息的情况。

  1. 01

    进入模型设置打开 Settings / Model / Provider 页面，优先查找 OpenAI Compatible、Custom API 或自定义模型供应商。

  2. 02

    选择兼容接口接口类型选择 OpenAI 兼容；如区分 Chat、Reasoning、Embedding，先只配置聊天 / 推理模型。

  3. 03

    复制平台字段Base URL 填平台接口地址，API Key 填平台密钥，Model 填完整模型名，不要修改大小写。

  4. 04

    保存并重启重新选择该供应商和模型；仍走旧配置时，检查项目级配置是否覆盖了全局配置。

字段对应表

Base URL

填写使用密钥页面里的接口地址，对应 Base URL、API Base、Endpoint 或 Server URL。

API Key

填写平台密钥；客户端要求 Header 时使用 Authorization: Bearer API_KEY。

Model

填写平台展示的模型名称。OpenClaw 设置默认模型时按 provider/model 格式选择。

Provider Type

优先选择 OpenAI Compatible / Custom OpenAI；Claude 兼容模式才使用 Anthropic 类型。

常见报错快速判断

  • 401：API Key 复制错误、密钥被禁用，或客户端没有保存成功。
  • 404：模型名写错，或密钥分组和模型类型不匹配。
  • 请求超时：检查网络代理、Base URL 是否完整，以及客户端是否需要开启系统代理。
  • 配置无效：保存后重启客户端，确认项目级配置没有覆盖全局配置。
命令行

Codex CLI 使用

先安装 Node.js 20 或以上版本，再通过 npm 安装 Codex CLI。已安装 Node.js 的用户可以直接跳过环境安装。

  1. 01

    检查 Node.js

    在终端输入 node -v。如果未安装，请从 Node.js 官网 下载安装包，安装时按提示完成。

    node -v
  2. 02

    安装 Codex CLI

    npm i -g @openai/codex
  3. 03

    国内镜像源备用

    如果安装失败或下载缓慢，可以先指定镜像源，再重新执行安装命令。

    npm config set registry https://registry.npmmirror.com
    npm i -g @openai/codex
  4. 04

    验证安装

    codex --version
  5. 05

    确认并启动

    确保 CC Switch 中已正确导入 Codex 密钥。随后在终端输入以下命令启动。

    codex

排查

常见问题

如果 CC Switch 配置没有生效，优先检查工具安装路径和配置文件目录。

CC Switch 配置为什么没有生效？
  1. 01

    检查工具安装路径

    确认对应 AI Agent 工具的安装路径是否正确。

  2. 02

    打开配置文件目录

    前往 CC Switch -> 设置 -> 高级 -> 配置文件目录。

  3. 03

    设置并重启

    将配置文件目录设置为 AI Agent 工具的正确安装路径，最后重启对应的 AI Agent 工具。

查看截图：配置文件目录
Codex 插件不能使用怎么办？
  1. 01

    安装 Codex++

    如果 Codex 插件入口无法使用或功能受限，推荐先安装 Codex++ 来解锁插件能力。

  2. 02

    重启后再检查

    安装完成后重启 Codex，再回到插件入口确认插件功能是否恢复。
